# Rede Concilia: Amigos do Bem

Crie um painel web completo de conciliação de cartões entre a adquirente Rede e o ERP, com a marca Amigos do Bem usando o logo anexado. Deve ser uma interface rica, em português, com sidebar de abas e ícones. Inclua visão operacional para conciliação diária e visão estratégica de projeções futuras, cobrindo conciliação de vendas e de recebíveis. Mostre dados e campos realistas que vêm da API da Rede, KPIs, alertas e exceções, vendas da adquirente ausentes no ERP, divergências de valores/taxas/parcelas, agenda de recebíveis, projeções de caixa, status de importação diária, filtros, tabelas detalhadas e ações de tratamento. Use padrões modernos de mercado para sistemas de conciliação e priorize excelente UX de dashboard financeiro.
